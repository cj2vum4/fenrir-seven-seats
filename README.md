# 諸神黃昏・七席舞台

手機瀏覽器的三輪對戰原型，提供七名玩家與一名主持人的房間模式，也保留單機試玩。前端為 GitHub Pages，房間由 Cloudflare Workers Free＋SQLite Durable Objects 保存與同步。

遊戲網址：https://cj2vum4.github.io/fenrir-seven-seats/

## 房間遊玩

1. 主持人開啟遊戲，選擇連線房間並建立房間，將房碼提供給七名玩家。服務網址已預填，日常不需修改。
2. 每名玩家用自己的手機瀏覽器輸入房碼，選擇一名尚未被使用的角色加入。請保留原瀏覽器的房間身分，勿清除網站資料。
3. 七人加入後，主持人設定初始力量／魔法牌與武器，再確認各角色血量。
4. 第一輪準備可交換或贈送武器；第二／三輪準備可加入力量與魔法牌。提案須由收件者接受才轉移物品，只允許存活角色交易。
5. 主持人開始戰鬥時取消全部未完成提案並鎖定交易。存活且本輪未行動者依最新血量排序行動；每人每輪一次。
6. 普攻力量牌造成 2 傷害、魔法牌造成 1 傷害；戰斧消耗 1 力量造成 3 傷害；炎劍消耗 1 力量，固定攻擊使用者左右鄰座各 2 傷害，第 1／7 席相鄰。武器本體保留，沒有每輪自動補牌。
7. 死亡者失去行動權，剩餘牌物一次移交擊殺者。輪末由主持人確認換座並進入下一輪準備，總共三輪；斷線或超時可由主持人接管目前角色。

## 目前範圍

已接入戰斧、炎劍、力量／魔法牌、交易、死亡掉落與房間同步。後端已通過八個獨立 HTTP 身分的公網三輪驗證；本機另有 Chrome 八端與 WebKit 交易驗證。這些結果不等於實體 iPhone／Android 各自行動網路整局及效能驗收。

正式場地、七名正式角色、3D 武器／戰鬥動畫、其他神器、角色技能／反應及陣營勝負判定仍待製作。芬里爾為靜態樣本，其餘六名與舞台仍是草模；未封版的同血量細節採介面明示的示範處理。

本原型僅使用免費服務，額度用盡時可能暫停操作。房間累計上限為 100，尚無封存清理介面；不提供跨瀏覽器的身分找回。請勿將手冊、Blender 來源、房間憑證或私人資料加入此公開儲存庫。
