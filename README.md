# 諸神黃昏・七席舞台

這是可在手機瀏覽器開啟的七席 3D 舞台預覽，包含七個高低座位、角色站位替身，以及芬里爾的靜態模型樣本。

## 使用方式

1. 開啟此儲存庫的 GitHub Pages 網址。
2. 在舞台上單指拖曳旋轉、雙指縮放，或切換全景、俯視與角色近看。
3. 調整角色血量，再按「套用輪末換座」預覽新座位。
4. 按「還原示範血量」回到預設樣本。

## 目前範圍

血量與座位設定只保存在目前瀏覽器。這個版本沒有多人同步、房間、交易或正式戰鬥結算；芬里爾目前為靜態樣本，其餘角色使用站位替身。

## 靜態部署

將此目錄的完整內容發布至 GitHub Pages，保留 assets 內的模型、圖片與解碼器相對路徑。index.html 位於發布目錄根層，.nojekyll 用來停用 Jekyll 處理。
