# 諸神黃昏・七席舞台

這是可在手機瀏覽器開啟的三輪單機戰鬥原型，包含七個高低座位、角色站位替身，以及芬里爾的靜態模型樣本。

## 使用方式

1. 開啟此儲存庫的 GitHub Pages 網址。
2. 由主持人設定初始血量並確認，再開始第一輪戰鬥。
3. 依目前行動者選擇目標，普通攻擊或放棄本次行動；每次攻擊後重新安排尚未行動的存活角色。
4. 本輪行動結束後，確認換座並進入下一輪準備。共三輪，第三輪完成最終換座後結束。
5. 可旋轉／縮放舞台，查看行動、目標、死亡與擊殺紀錄；重新整理可保留進度。
6. 「重新開局」需確認後才清除目前進度。

## 目前範圍

由同一個瀏覽器輪流操作七名角色與主持人，進度只保存在目前瀏覽器，尚無多人同步或房間。

普通攻擊固定 2 點傷害，用來測試流程；尚未計算牌數、武器、技能、反應或交易，也不判定陣營勝負。首輪同血量、放棄行動納入順位、未行動者補位與輪末同血量參照先採明示的示範處理，正式規則待確認。

正式場地、七名正式角色、戰鬥動畫與實體手機效能仍待驗收；芬里爾目前為靜態樣本，其餘六名使用站位替身。

## 靜態部署

將此目錄的完整內容發布至 GitHub Pages，保留 assets 內的模型、圖片與解碼器相對路徑。index.html 位於發布目錄根層，.nojekyll 用來停用 Jekyll 處理。

此儲存庫保存部署產物；可編輯原始碼在本機專案的 web/，請先建置再同步完整 dist。
