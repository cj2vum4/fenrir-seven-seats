# 諸神黃昏・七席舞台

這是可在手機瀏覽器開啟的三輪單機戰鬥原型，包含攻擊牌、戰斧、固定攻擊左右鄰座的炎劍，以及擊殺牌物移交。七席場地與其餘角色仍為草模，芬里爾為靜態模型樣本。

## 使用方式

1. 開啟此儲存庫的 GitHub Pages 網址。
2. 由主持人設定七名角色的初始牌數與武器；力量 2＋魔法 2 是可編輯預設，不是每輪補牌。
3. 炎劍固定攻擊使用者左右兩側，第 1／7 席相鄰，不需選擇範圍規則。確認道具後，再設定初始血量並開始第一輪戰鬥。
4. 每次行動選力量牌（1 張／2 傷害）、魔法牌（1 張／1 傷害）、戰斧（力量 1 張／3 傷害）或炎劍（力量 1 張／合法雙目標各 2 傷害）。一次只使用一把武器，武器本體保留。牌不足不能攻擊，也可放棄而不耗牌。
5. 選用炎劍後自動標示左右兩席，不能改選；死亡鄰座不替換成其他存活者。範圍依當輪固定座位，一次結算全部目標；新擊殺會移交死者剩餘牌及本版武器，死者再次被攻擊不重複掉落。
6. 本輪結束後確認換座並進入下一輪準備，共三輪；第三輪最終換座後結束。
7. 重新整理可保留進度；確認「重新開局」才清除本版紀錄。舊版 v3／v2 紀錄保留，v4 從初始道具開局，不改寫舊測試局的範圍判定。

## 目前範圍

由同一個瀏覽器輪流操作七名角色與主持人，進度只保存在目前瀏覽器，尚無多人同步或房間。

尚未接入角色技能、反應、其他神器、交易與陣營勝負。首輪同血量、放棄行動納入順位、未行動者補位與輪末同血量參照先採明示的示範處理；炎劍的固定左右鄰座與首尾相鄰已由使用者確認。

正式場地、七名正式角色、3D 武器／戰鬥動畫與實體手機效能仍待驗收；本次武器功能為資料、結算及介面支援。

## 靜態部署

將此目錄的完整內容發布至 GitHub Pages，保留 assets 內的模型、圖片與解碼器相對路徑。index.html 位於發布目錄根層，.nojekyll 用來停用 Jekyll 處理。

此儲存庫保存部署產物；可編輯原始碼在本機專案的 web/，請先建置再同步完整 dist。
